# Brains

A working roster for this fictional demo, checked 2026-11-22. Choose one operator for each edit so two models do not overwrite each other. Give it CLAUDE.md and the relevant source files. Ask for changed paths at handoff. A chat does not see local files unless you provide access.

## Claude

Main operator inside the vault. Edits notes, runs skills and routines.

- Use it for: filing captures, logging workouts, updating reviews.
- Don't use it for: sending messages, deleting notes or making purchases without permission.
- Example prompt: "Read CLAUDE.md and run inbox-triage. Show the proposed destinations before moving notes."

## ChatGPT/Codex

Overflow work, images and a second opinion. Codex can work in a granted local folder. Project uploads are copies.

- Use it for: checking a debt table, drafting a diagram, making a video image.
- Don't use it for: assuming an uploaded copy stays synced with Obsidian.
- Example prompt: "Read these notes and challenge my weekly priorities. Return edits by file path."

[Project file guidance](https://help.openai.com/en/articles/10169521-using-projects-in-chatgpt).

## Gemini

Huge context work: long PDFs, whole folders and video. Supply files within the limits of your account.

- Use it for: synthesizing a course packet or reviewing a long video.
- Don't use it for: treating every detail in a long context as verified.
- Example prompt: "Summarize this course folder. Cite file names and separate facts from open questions."

## Grok

Live news and what people say on X. Grok Automations can schedule checks. Social posts are leads to verify.

- Use it for: a dated news digest with primary links and a separate X reaction section.
- Don't use it for: financial decisions based on sentiment or guessing local vault changes.
- Example prompt: "Find this week's AI news for my channel. Link original announcements. Label rumors."

[Automations setup](https://x.ai/news/grok-automations).

## Meta AI with Muse

Muse Spark is the model. Muse is the agent app. In this demo it is the social media agent: drafts posts, answers comments, researches trends and checks marketplace prices. Available actions depend on connected accounts and permissions.

- Use it for: drafting replies, comparing public asking prices and proposing post ideas.
- Don't use it for: sending, publishing, buying or sharing private notes without checking in first.
- Example prompt: "Draft replies to these comments and compare used tripod prices. Show drafts and source links. Check with me before sending or buying."

[Meta's Muse introduction](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/) and [Muse Spark introduction](https://about.fb.com/news/2026/04/introducing-muse-spark-meta-superintelligence-labs/).
