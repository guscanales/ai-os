# Training Program

Fictional working weights, updated 2026-11-19. Weight is total load unless marked per hand. Warm-up sets are excluded. RIR means reps in reserve: finish the last working set feeling able to do 1 to 2 more clean reps.

## Monday: Pull

| Exercise | Sets x reps x weight |
|---|---|
| Cable row | 4 x 10 x 90 lb |
| Lat pulldown | 4 x 10 x 100 lb |
| Face pull | 4 x 15 x 30 lb |
| Dumbbell curl | 2 x 12 x 20 lb per hand |

## Progression

Add 5 lb at the next session when every prescribed rep is hit with clean form and the last set remains at RIR 1 to 2. For dumbbells, that means 5 lb per hand, only if the next pair is manageable. If not, repeat the weight. Bodyweight moves progress by control and range, not added weight by default.

This is a pull-biased split after trainer advice for posture and neck pain. There are 12 upper pulling sets and 6 upper pressing sets, about 2 pull sets per push set. Arm isolation and lower body work are excluded from that ratio.

Record actual sets, missed reps and discomfort in [[Areas/Health/Workout Log]]. Never increase a load from an incomplete log.
