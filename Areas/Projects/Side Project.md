# Side Project

Habit tracker app. Fictional idea, parked until the video and study routine are stable.

## Problem

A person starts too many habits and loses track of the one that matters this week.

## Small experiment

Use a Markdown table for one habit before building software. Test with seven days of evening reading. Ask whether the reminder helped and whether logging felt like work.

| Decision | Current choice |
|---|---|
| User | One person |
| First feature | One habit, one weekly review |
| Excluded | Social feed, streak rewards, payments |
| Success signal | Logged at least 5 of 7 days and wants a second week |

No code needed for the first test. Planning action is in [[Tasks]].
