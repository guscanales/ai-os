# Job Fit Rules

FAKE example preferences. These do not describe Gus's actual compensation or employment needs.

| Rule | Demo preference |
|---|---|
| Salary floor | $150K base in USD |
| Location | Remote in the US, or hybrid up to 2 days per week within a self-chosen commute |
| Contract type | Full-time employee preferred; fixed-term contract only after reviewing benefits and duration |
| Level | Senior individual contributor |
| Must-haves | Backend ownership, practical AI work, code review, time for evaluation |
| Deal-breakers | Unpaid trial work, unclear pay, mandatory relocation, routine overnight on-call |

Unknown pay is a question, not a pass. A role below the floor is a misfit even if the technology sounds interesting. See [[Areas/Career/Resume Notes]] for evidence. The AI recommends; Gus chooses whether to apply.
